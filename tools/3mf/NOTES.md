# Разбор присланных моделей

Рабочий порядок: человек присылает 3MF/STL печатного теста → он разбирается здешними инструментами →
раскладка и размеры повторяются моделью генератора.

```
tools/3mf/analyze.sh parts   FILE                    # сколько деталей, какие габариты
tools/3mf/analyze.sh map     FILE 0 140 55           # карта высот сверху, псевдографикой
tools/3mf/analyze.sh feat    FILE 0 0.3              # выступы / сквозные отверстия / карманы списком
tools/3mf/analyze.sh profile FILE 0 x 105.5 24 224   # профиль поверхности вдоль прямой
```

**Вверх у 3MF — это Z.** Импорт осей не переставляет (как и у STL), поэтому X и Y здесь — стол, а Z —
высота. Ошибиться тут стоит целой раскладки: «высота 50» окажется глубиной плиты.

Инструменты собирают бандл из НАСТОЯЩЕГО `<script>` страницы и зовут её же `parseMeshFileParts`.
Своего разборщика тут нет намеренно: он читал бы файлы, которых не читает генератор, и молчал бы о том,
на чём генератор спотыкается. Разбор семи файлов с MakerWorld именно так и нашёл, что пять из семи
возвращали ноль деталей (расширение Production — геометрия в отдельных `3D/Objects/*.model`), — это
починено в v18.4.2.

## Замеры

Ниже — то, что СНЯТО с сеток. Числа — факты, толкование помечено отдельно. Файлы дважды уничтожал сброс
контейнера, поэтому замеры записаны сюда: пережить сброс должны хотя бы они.

### `measure_tool.3mf` — 2 детали, 699 235 треугольников

| деталь | габарит X×Y×Z | треугольников |
|---|---|---|
| Деталь 5 | 20 × 170 × 14 | 96 990 |
| Деталь 12 | 200 × 200 × 21.5 | 602 245 |

Деталь 12 — плита 200×200, верх плиты на Z = 5.5, низ на Z = 1.42; по углам четыре сквозных отверстия
Ø ≈ 18. Станции рядами по Y:

| Y | что снято |
|---|---|
| 29.3 | одна фигура 40×40 высотой 16 при x = 42.7 + шесть карманов 20×20 глубиной 4.08 при x = 80.2, 104.6, 129.2, 153.5, 178.1, 202.7 |
| 67…76 | одиночные тела: 25×25 h 12.5 · 20×20 h 10 · 15×15 h 15 · 15×15 h 7.5 · 15×15 h 15 · 10×10 h 5 · 10×10 h 10 · 10×10 h 10 · 5×5 h 5 · 5×5 h 2.5 · 5×5 h 5 |
| 105.5 | восемь станций 20×20 с шагом 24.9; высоты 5, 5, 5, 5, 5, 5, 3.6, 1.74; переход от плиты к верху занимает по X ровно 1, 2, 3, 4 … мм — то есть кромка скруглена растущим радиусом |
| 136.0 | восемь площадок 20×20 высотой 1.0, площадь ≈ 70 из 400 — это подписи |
| 161.0 | восемь станций 20×20 высотой 14, площадь ≈ 148 из 400 |
| 194.5 | полоса 200×30 высотой 5 во всю ширину |

**Толкование (не проверено повторным замером):** ряд 105.5 — скругления, ряд 161.0 — конусы или пирамиды
(площадь у порога +0.6 мм вчетверо меньше квадрата основания, так что тело сходится кверху), ряд 29.3 —
купол плюс карманы, ряд 67…76 — проверка размеров кубами и цилиндрами 5…25.
